# One Games

Loja de games em React + TypeScript + Vite + Tailwind CSS + Axios, com carrossel, capas, favoritos e carrinho. Dados via [RAWG API](https://rawg.io/apidocs).

## Stack

- React 18 + React Router
- TypeScript + Vite
- Tailwind CSS
- Axios
- Swiper (carrosséis)
- Framer Motion
- React Icons / Radix Icons / MUI Joy

## Como rodar

```bash
npm install --legacy-peer-deps
npm run dev
```

Build de produção:

```bash
npm run build
npm run preview
```

## Funcionalidades

- Home com marca One Games
- Loja com lançamentos, tops, plataformas e gêneros
- Página do jogo com screenshots e metadados
- Busca com debounce
- Favoritos e carrinho (localStorage)
- Interface em português (pt-BR)
